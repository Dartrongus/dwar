Первый способ (Браузер)

1. Копируем код

JavaScript Bookmarklet
Кнопка «Копировать» находится над полем с кодом.

2. Создаём новую закладку в браузере с кодом

Как создать закладку?

Правой кнопкой мыши по панели закладок → «Добавить страницу». Название пунктов может отличаться в разных браузерах. Если не получается, загуглите, как создать закладку в вашем браузере.

Если не нашли, попробуйте сочетание клавиш Ctrl + D. Это создаст закладку текущей страницы, после чего можно изменить её название и вставить код в поле URL.

Даём любое название, в поле URL вставляем код из первого пункта и нажимаем «Сохранить».

3. Открываем персонажа в браузере ПОЛНОСТЬЮ

Если у персонажа стоит образ, жмём кнопку «Перейти к игровой информации».

Закрытых персонажей посмотреть нельзя!

4. Жмём на созданную закладку

Вверху страницы появятся вещи персонажа.

Можно навести курсор, чтобы увидеть более подробную информацию о вещах или кликнуть для открытия в новой вкладке.

Второй способ в Dwarium

1. Копируем код

JavaScript Bookmarklet
Кнопка «Копировать» находится над полем с кодом.

2. Открываем и создаём заметку

Вставляем код в заметку.

3. Открываем персонажа в браузере ПОЛНОСТЬЮ

Если у персонажа стоит образ, жмём кнопку «Перейти к игровой информации».

Закрытых персонажей посмотреть нельзя!

4. Вставляем код из заметки в адресную строку и жмём Enter
